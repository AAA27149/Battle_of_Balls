# Battle of Balls

一款多人联机碰撞小球游戏。



网络方面

传输层协议使用Socket+Tcp实现，应用层协议使用消息头+消息体的形式实现，序列化协议使用Protobuf的Message实现
同步方面

同步使用的是状态同步，主机权威



多人只有1到4人，相关数据都在主机上算，所以用状态同步，传输用Socket+Tcp，人数少，加入，退出和短时间内的同步结果，都要按顺序送到，Tcp能保证这一点



游戏玩法

1、创建房间，输入指定的ip和端口号，ip使用的是本机地址，127.0.0.1

2、加入房间，输入指定的ip和端口号，进入房间

3、鼠标左右移动控制视角，键盘wasd移动控制位移

4、控制玩家碰到小球会将小球撞飞，小球碰到墙会弹回来

5、房间最多4人。1号红色是主机，2号蓝色，3号绿色，4号紫色。人满后再加入会提示房间已满

6、玩家加入时会同步正在滚动的小球和移动的玩家，玩家退出时，这个玩家的模型会消失，主机断开时，其他人会看到“主机已断开连接”，点击确定返回主界面

7、主机每15秒在房间里随机生成一个球，玩家碰到球会提示Tapped
